------ATIVIDADE DECLARAR VARIÁVEIS E CRIAR FUNÇÕES EM TYPESCRIPT------
- Primeiro definimos um type chamado "veiculo" contendo os objetos {modelo do tipo string e ano do tipo number};
- definimos as variáveis em associação ao objeto "veiculo", ex: modelo 'Kicks' ano 2026;
- criamos uma função chamada "nomeCarro" onde carango será associada a "veiculo";
- o if está contendo a lógica que o modelo === Kicks, se a condição estiver de acordo, exibirá uma mesagem positiva no console.log
- senão estiver de acordo, exibirá uma mensagem informando a condição também no console.log
- por último chamamos a função "nomeCarro" para retornar o resultado.
